Repository layout
6 October 2026

Player installation

paultendo-mod.js is the independently installable overhaul. Use the
versioned CDN URL and instructions in README.md. The inherited utilities
listed in THIRD_PARTY_NOTICES.txt are not required for this installation.

Local game

index.html adapts the original GenTown page. app/ contains the original
paultendo launcher support and presentation changes. vendor/gentown/
contains the upstream engine, styles and fonts. icons/ contains the
original game icons used by the engine and launcher. Keep both directories.
app/sprites/ holds the added 32x32 exports, palette renderer, built data and
comparison page. artwork/paultendo-sprites/ holds source artwork,
prompts, hashes and a technical usage guide. These are separate from icons/.
scripts/build-sprites.mjs embeds the art and renderer in paultendo-mod.js.
The installed mod does not fetch these development files at runtime.

Development and verification

scripts/ contains the loopback development server and campaign harness.
tests/ checks simulation behaviour, resource conservation and compatibility.
package.json and package-lock.json describe the development dependencies.
docs/release-1.6.92.txt and docs/qa/ preserve the evidence for the published
v1.6.92 release. They describe that release, not later untested changes.
docs/release-1.6.93.txt records the subsequent headline alignment correction.
docs/release-1.6.94.txt records the controls, dependency views, routine
update folding, map repairs and performance work. Its QA record retains
the passing suite, campaign summaries, benchmark and browser checks.
docs/release-1.6.95.txt records the sprite, palette, overlay and layout checks.
docs/mod-comparison-2026-10-05.txt and its QA record describe the other
mods inspected before this work, with exact source hashes and limits.
docs/screenshots/ contains genuine game captures used in the README, with
their source campaign and capture details in captures.txt.

hot-swap-mod.js is paultendo's separate development utility. It is not
loaded by the default launcher. Updating the overhaul still requires a
page reload, as described in README.md.

Documentation

README.md describes the current release, installation and comparison with
base GenTown. LICENSE.md separates ownership and permissions.
THIRD_PARTY_NOTICES.txt identifies inherited assets and utilities.
docs/provenance-2026-10-06.txt records the source comparison and attribution.
docs/provenance-2026-10-06.json inventories the audited Git tree, file
hashes, first recorded commits and comparison results. The audit can be
repeated with scripts/audit-provenance.py without executing the game.
docs/campaign-harness.txt describes the simulation runner.
docs/mod-notes.txt is a dated development record, including older results
and limitations. It is not the current installation guide.
The earlier root-level design plans and assessments have been removed.
Their previous contents remain in Git history. Current behaviour and
remaining limits belong in README.md and the implementation notes.

Inherited independent utilities

better_mod_loader.mjs, whirl-load.js, world-configurator.js, example_mod.js
and mods.json are retained at their original paths for existing links.
They have separate provenance and are not part of the tested overhaul.
Moving or deleting them could break users' existing installation URLs.
